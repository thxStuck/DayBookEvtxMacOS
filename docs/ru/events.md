## Окно кейса

Слева — боковая панель, справа — выбранный раздел и, где это нужно, панель деталей события.
Заголовок окна — имя кейса и «N событий · M файлов».

| Раздел | Что показывает |
|---|---|
| События | Таблица событий с запросом, фильтрами, гистограммой и группировкой |
| Таймлайн | Те же события единой лентой с разделителями дней и пауз |
| Журналы | Один журнал, как в «Просмотре событий» Windows |
| Детекты | Срабатывания правил Sigma — см. [Sigma-детекты](detections.html) |
| Хосты, Пользователи, IP-адреса | Реестр сущностей — см. [Сущности](entities.html) |
| Сеансы | Сеансы входа и RDP-цепочки |
| Процессы | Деревья процессов Sysmon и Security 4688 |

Счётчики рядом с разделами: у «Журналов» — число журналов с событиями, у «Детектов» — число
сработавших правил, у реестров — число сущностей.

Панель инструментов справа: «Сведения о кейсе» (ⓘ), часовой пояс, «Экспорт», «Гистограмма»,
«Детали».

## Раздел «События»

Сверху вниз: строка запроса, строка фильтров, гистограмма, таблица. При группировке слева
появляется панель групп.

### Строка запроса

- Запрос на [языке DQL](dql.html). Выполняется по Return или ⌘↩, кнопка «Стоп» прерывает выполнение.
- Крестик очищает запрос.
- Меню с часами — история последних запросов.
- «?» — краткая подсказка по языку.

### Фильтры

Фильтр — чип под строкой запроса: «Поле = значение» или «Поле ≠ значение» (красный). Оранжевый чип —
интервал времени. Запрос выполняется поверх чипов.

Как добавить фильтр:

- **Таблица** — правый клик по ячейке: «Фильтр = …» или «Исключить ≠ …».
  В ячейке описания — подменю по каждому полю события.
- **Детали** — правый клик по строке поля.
- **Боковая панель** — клик по значению: «=», ⌥-клик — «≠».
- **Гистограмма** — выделение протягиванием и кнопка «Фильтр по выделению».

С чипом можно: щелчком выключить и включить, через меню сделать «=»/«≠» или удалить, удалить
крестиком.

«Сбросить всё» (⌘K) убирает запрос, все фильтры и интервал времени. Прежние запросы остаются в
истории.

### Таблица

- Колонки по умолчанию: Время, Компьютер, Журнал, ID, Уровень, «Описание / данные события».
- Меню «Колонки» (правый клик) добавляет Пользователя, Источник, Пользователя (SID), Файл,
  RecordID. Любое поле события добавляется пунктом «Добавить колонку». Стадия `| select` задаёт
  колонки целиком.
- Колонки перетаскиваются и меняют ширину; клик по заголовку «Время» меняет порядок.
- **Уровень** для событий аудита — «Аудит успеха» / «Аудит отказа» по Keywords, иначе Критический,
  Ошибка, Предупреждение, Сведения, Подробно.
- **Описание.** Для частых событий — понятный текст на русском или английском: входы, Kerberos,
  процессы, службы, задачи, PowerShell, Sysmon, RDP, Defender и другие. В текст подставлены
  расшифровки: тип входа, коды NTSTATUS и ошибок Kerberos, типы шифрования, коды `%%NNNN`. Опасные
  признаки отмечены ⚠ (доступ к lsass, RC4, вход без преаутентификации, признаки DCSync, очистка
  журналов). Для остальных событий — «Поле: значение · …».
- **Цвет времени:** красный — ошибка разбора записи; оранжевый — запись восстановлена из slack,
  из устаревшего чанка или после повреждённого участка.
- Строка с закладкой подкрашена цветом закладки.
- Клик по строке открывает событие в панели деталей.
- Правый клик: фильтры, «Закладка», «Копировать строку» (значения через табуляцию), «Колонки».

### Группировка

Запрос с `| group by` показывает слева панель групп: число событий и значения полей. «—» — у событий
нет этого поля. Если групп больше 20 000, число отмечено «+».

- Клик по группе показывает её события.
- Двойной клик или «Превратить в фильтры и показать события» превращает значения группы в чипы
  и убирает `group by` из запроса.
- По умолчанию группы идут по убыванию числа событий.

### Боковая панель

**Пресеты** — готовые запросы по темам: входы и учётные записи, Kerberos/NTLM, выполнение и
закрепление, сокрытие следов, доступ к ресурсам, особенности журналов. Клик заменяет текст запроса,
чипы остаются. Тексты всех пресетов — в разделе [DQL](dql.html#готовые-запросы).

Дальше — фасеты со счётчиками по **всему кейсу**:

| Секция | Клик |
|---|---|
| Детекты | Срабатывания по уровням правил; клик — `rulelevel = …`, «Все сработавшие правила…» — раздел «Детекты» |
| Файлы журналов | Фильтр по файлу; метка `dirty`, в подсказке путь и SHA-256 |
| Закладки | Переход к событию |
| Хосты, Пользователи, IP-адреса | Фильтр «… (любая роль) = …»; ⌥-клик исключает |
| Журналы, Компьютеры, Event ID, Флаги записей | Фильтр «=», ⌥-клик — «≠»; «все значения…» — `group by` по полю |

Клики в боковой панели **уточняют текущий поиск**. Переходы из других разделов (сущности, сеансы,
процессы, детекты, журналы) начинают новый поиск.

## Гистограмма

- Распределение текущего результата по времени (до `sort` и `limit`), около 160 столбцов. Ширина
  столбца подбирается автоматически: от 1 секунды до 1 года.
- Протяните мышью по графику и нажмите «Фильтр по выделению» — появится оранжевый чип интервала.
- **Выбросы.** Если событий больше 1000, ось строится по 0,1–99,9 перцентилю, чтобы одна запись с
  датой 1601 или 2099 года не сплющивала график. Под графиком написано, сколько событий вне оси, и
  есть ссылка «показать всё». Выбор запоминается.
- Скрыть или показать — кнопка «Гистограмма» на панели инструментов.

## Таймлайн

Единая лента событий с тем же запросом и фильтрами, что в «Событиях».

- Колонки: Время, Журнал (с цветной точкой по каналу), Компьютер, Пользователь, ID, Описание.
- Колонка «Пользователь» берёт первое из полей: User, TargetDomainName\TargetUserName,
  SubjectDomainName\SubjectUserName, AccountDomain\AccountName, Param1, SID из System.
- Смена дня отмечена линией, пауза больше часа между соседними событиями — пунктиром и строкой
  «⏸ пауза …».

## Журналы

Просмотр одного журнала, как в «Просмотре событий» Windows. Запрос и фильтры раздела «События»
при этом не меняются.

- **Дерево в боковой панели:** «Журналы Windows» (Application, Security, Setup, System,
  ForwardedEvents) и «Журналы приложений и служб», сгруппированные по поставщику. Журнал
  определяется по имени файла. Флажок «Без пустых» скрывает пустые журналы.
- **Шапка:** журнал, число записей (и сколько восстановлено из slack), путь к файлу,
  кнопка «Открыть в «Событиях»».
- **Фильтр:** чипы уровней (Критический, Ошибка, Предупреждение, Сведения, Подробно), для Security —
  «Аудит успеха» и «Аудит отказа», поле «Фильтр DQL» (Return) и кнопка «Сбросить».
- Новые события сверху. Под таблицей — панель деталей, высота меняется перетаскиванием.
- «Открыть в «Событиях»» начинает новый поиск в «Событиях» по этому журналу с теми же уровнями и
  фильтром DQL.

## Панель деталей

Справа в «Событиях», «Таймлайне», «Сеансах» и «Процессах», внизу в «Журналах». Кнопка «Детали»
показывает и прячет её, ширина меняется перетаскиванием границы.

### Вкладка «Поля»

1. **Сработавшие правила** — уровень, название, автор и набор правил; клик открывает правило.
2. **Система:** описание, закладка, время в выбранном поясе и в UTC (7 знаков), время записи в журнал,
   если отличается, EventID, журнал, источник, компьютер, уровень, SID пользователя, EventRecordID,
   Task, Opcode, Keywords, ProcessID / ThreadID, файл и путь, флаги словами.
3. **Данные события** — все поля EventData и UserData в порядке записи. Коды `%%NNNN` показаны как
   «текст (код)».
4. **Копии этой записи** — если были объединены копии: файл, чанк и смещение каждой.

Правый клик по полю: «Фильтр = …», «Исключить ≠ …», «Добавить колонку», «Копировать значение»,
«Копировать «имя: значение»».

Вкладка «Поля» берёт данные из кейса и работает, даже если исходного файла уже нет.

### Вкладки XML и Hex

XML записи и её байты (по 16 в строке, со смещением и ASCII) читаются из исходного журнала.
Пока он читается или если недоступен, вкладка объясняет причину:

| Сообщение | Что значит |
|---|---|
| Читаю запись из исходного файла… | Файл открывается |
| Файл не отвечает дольше 3 секунд… | Сетевая папка недоступна, диск спит или macOS ждёт разрешения на доступ |
| Исходный файл не найден… | Журнал перемещён или удалён после импорта |
| macOS не дала доступ к исходному файлу… | Разрешите доступ в «Файлы и папки» |
| По сохранённому положению в файле другая запись… | Файл изменился после импорта |

Под сообщением показан путь, по которому ожидается файл.

## Часовой пояс

Меню с часами на панели инструментов:

- UTC (по умолчанию);
- «Смещение UTC±» — 37 фиксированных смещений от −12:00 до +14:00, включая +05:45 и −09:30;
- «Часовой пояс (с переходом на летнее время)» — 24 зоны IANA;
- «Локальное время Mac».

Время в кейсе хранится в UTC. Пояс меняет время в таблице и деталях, заголовок колонки времени,
ось гистограммы, разделители дней в таймлайне, понимание времени в запросах и колонку времени в
экспорте. В деталях всегда видно и время UTC. В таблице — миллисекунды (лишние цифры отбрасываются,
а не округляются).

## Закладки и заметки

- ⌘B (меню «Событие» → «Закладка») ставит красную закладку на выбранное событие или снимает её.
- Правый клик → «Закладка»: шесть цветов, «Заметка…», «Убрать закладку». Заметка без закладки
  ставит жёлтую. У события одна закладка.
- Закладки видны цветом строки, в деталях и в разделе «Закладки» боковой панели; клик по ней
  переходит к событию.
- Поиск: `tag = red`, `tag in (red, blue)`, `tag = *`.
- Закладки хранятся в кейсе. Текст заметок не ищется и не экспортируется.
